# Dossiê de espécie — *Amazona amazonica*

Dossiê OSINT da espécie *Amazona amazonica* (papagaio-do-mangue / orange-winged amazon), preparado para a biblioteca da Área Restrita do Observatório Global de Tráfico de Animais.

## Envio manual do relatório

Envie o PDF original diretamente para esta pasta do GitHub, com o nome exato:

`dossie_Amazona_amazonica_OSINT_2026-10-21.pdf`

Caminho completo:

`reports/internal/species/amazona-amazonica-2026-10-21/dossie_Amazona_amazonica_OSINT_2026-10-21.pdf`

O registro está incluído no catálogo trilíngue `reports-internal.json`, categoria `species`, com metadados em português, inglês e espanhol. O documento é listado em **Área Restrita > Relatórios Internos > Relatórios de espécies**. O acesso ao PDF só deve ser habilitado após a confirmação de sua existência no repositório.

**Observação sobre acesso:** este repositório é público. O PDF poderá ser acessado diretamente pela URL, independentemente do login da Área Restrita. Verifique o documento antes de enviá-lo, especialmente quanto a dados pessoais e informações investigativas sensíveis.
