# Dossiê OSINT — *Podocnemis expansa*

## Relatório

**Título:** Dossiê OSINT: *Podocnemis expansa* - Apreensões de ovos e indivíduos, geografias e rotas documentadas.

Este diretório é o local de publicação do PDF do dossiê de espécie na biblioteca da Área Restrita do Observatório Global de Tráfico de Animais, conforme o padrão dos relatórios de *Corallus cropanii*, *Melipona capixaba* e *Amazona amazonica*.

## Envio manual do PDF

Enviar nesta pasta o PDF com o **nome exato**:

`dossie_Podocnemis_expansa_OSINT_2026-11-07.pdf`

Caminho completo:

`reports/internal/species/podocnemis-expansa-2026-11-07/dossie_Podocnemis_expansa_OSINT_2026-11-07.pdf`

O relatório está pré-cadastrado no arquivo `reports-internal.json`, categoria `species`, com títulos e descrições em português, inglês e espanhol e `scientific_name` para apresentação em itálico.

**Após subir o PDF:** confirmar que o arquivo existe no caminho acima e alterar `files.pt.available` de `false` para `true` no catálogo, para habilitar o acesso. Não usar link para um PDF inexistente.

**Confidencialidade:** este repositório GitHub é público. O PDF poderá ser aberto diretamente pela URL por qualquer pessoa, mesmo sem autenticação na Área Restrita. Verificar se o documento pode ser publicado antes de enviá-lo.
